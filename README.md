# wild-rose-charleston-website
Wild Rose Charleston Website Redesign
Title: "Wild Rose Charleston Website Redesign" 

Project purpose: a redesign proposal for Dr. Rachel McIntyre's practice website to improve clarity, navigation and online booking 

Website objectives: Modern responsive design, better user experience, clear service info, accessibility compliant, and Jane booking integration 

Planned pages: Home, services, about Dr. Rachel, contact, and checkout or book appointment 

Roadmap phase one is planning and design. Sitemap, wireframes and color palette selections. Phase two, build core pages. Phase 3, integrate booking and checkout. Phase four, test accessibility, fix issues and launch. 

Technologies, HTML5, CSS3, GitHub, Figma
