# Wild Rose Charleston Website Redesign

## Project Purpose

This project proposes a modern, accessible, and user-friendly website redesign for Wild Rose Charleston, the private acupuncture practice of Dr. Rachel McIntyre. The redesign is intended to improve website navigation, clearly communicate services, and create a simple online booking experience.

## Website Objectives

- Create a modern and responsive website design.
- Improve the overall user experience and navigation.
- Clearly present acupuncture services and pricing.
- Provide a simple and intuitive appointment-booking experience.
- Follow accessibility best practices.
- Connect users to the Jane online booking system.

## Planned Website Pages

- Home
- Services
- About Dr. Rachel
- Contact
- Checkout / Book Appointment

## Future Development Roadmap

### Phase 1 — Planning and Design
- Create the website sitemap.
- Develop wireframes and page layouts.
- Select the brand colors and typography.
- Establish the visual design direction.

### Phase 2 — Core Website Development
- Build the homepage.
- Build the services page.
- Build the About and Contact pages.
- Implement responsive navigation and mobile-friendly layouts.

### Phase 3 — Booking and Checkout
- Add service information and booking options.
- Connect users to the Jane booking system.
- Develop the checkout/appointment flow.
- Test the booking experience.

### Phase 4 — Testing and Launch
- Test website navigation and links.
- Test the booking flow.
- Check accessibility and color contrast.
- Test the website on mobile and desktop.
- Fix bugs and prepare the website for launch.
