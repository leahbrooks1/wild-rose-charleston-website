Wild Rose Charleston

Website Redesign Proposal

Project Overview

This project proposes a modern, accessible, and user-friendly website redesign for Wild Rose Charleston, the private acupuncture practice of Dr. Rachel McIntyre.

Project Goals

  • Create a clean and professional visual design.
  • Make acupuncture services easy to understand.
  • Provide a simple and clear appointment-booking experience.
  • Improve website navigation and accessibility.
  • Connect users to the online booking system.
